# Count Digits

## Problem Statement

Given a positive integer `n`, count how many digits it contains.

## Examples

### Example 1
**Input:** `7`  
**Output:** `1`

### Example 2
**Input:** `42`  
**Output:** `2`

### Example 3
**Input:** `100000`  
**Output:** `6`

---

## Constraints

- `1 <= n <= 10^18`

---

## Rules

- ❌ Do **not** convert the number into a string.
- ❌ Do **not** use built-in functions that count digits.
- ✅ Use only mathematical operations.
